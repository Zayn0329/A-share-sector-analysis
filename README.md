# A-share-sector-analysis · 全市场指数与行业板块资金监控台

> **当前版本：v1.04**（2026-11-09）
> 一个零第三方依赖的 Node.js 前后端项目：上方盯三大指数分时，中间按「涨跌幅 × 流通总市值」给全市场板块排序，用线条长度直观呈现主力资金流向。
> 完整更新记录见 [CHANGELOG.md](./CHANGELOG.md)；版本一律**最新在上、旧版本在下**。

原始仓库说明：*This page is mainly dedicated to A-share sector analysis.* 本项目在此基础上扩展为可运行的实时行情看板。

## 三、这个页面能用来做什么

- **盘中盯盘**：三大指数同屏，配合分时量判断趋势是否放量。
- **板块轮动观察**：用「市值加权涨跌」找出真正带动指数的方向，而不只是涨幅榜上的小板块。
- **资金验证**：排序结果旁的线条与四档单量明细，用来验证上涨是否有主力资金配合。
- **复盘**：休市时展示最近交易日完整分时与收盘板块数据，可用于收盘后复盘。

> 排序指标 `涨跌幅(%) × 流通总市值` 是按公开数据计算的**方向性估算值**，不等于真实市值变动额；仅用于横向排序，不作为财务或估值口径使用。

## 四、快速开始

环境要求：**Node.js ≥ 18**（使用内置 `fetch`，无需 `npm install`，项目零第三方依赖）。

```bash
cd money
npm start
```

或 Windows 下双击 `start.bat`。浏览器打开 **http://127.0.0.1:8787**。

自定义监听地址与端口：

```bash
PORT=9000 HOST=0.0.0.0 npm start
```

> 后端与前端必须一起启动；单独用静态服务器打开 `public/index.html` 会因为拿不到 `/api/*` 而没有数据。
> **不打开 WorkBuddy 时怎么运行，见第五节。**

## 五、不打开 WorkBuddy 时如何运行

**结论：WorkBuddy 只是当初用来写这个项目的工具，运行时完全不需要它。** 这个程序就是一个普通的 Node.js 服务，代码老老实实躺在项目目录里，只要能启动 `server.js`，浏览器打开 `http://127.0.0.1:8787` 就能用。

### 4.1 唯一前提：Node.js ≥ 18

本机**没有装系统级 Node.js**，只有 WorkBuddy 自带的便携版：

```
C:\Users\Mr_Chen\.workbuddy\binaries\node\versions\22.22.2-6\node.exe
```

它只是硬盘上的一个 exe，**WorkBuddy 关掉后依然存在**，所以脚本可以直接调用。但普通 CMD / PowerShell 的 PATH 里搜不到它，因此 `start.bat` 会按以下顺序自动定位 `node.exe`：

1. 环境变量 `WB_NODE_EXE`（自定义路径，优先级最高）
2. PATH 中的 `node`
3. `%ProgramFiles%\nodejs\node.exe`、`%LOCALAPPDATA%\Programs\nodejs\node.exe`
4. `%USERPROFILE%\.workbuddy\binaries\node\versions\*\node.exe`（WorkBuddy 便携版）

自检命令（终端里执行，只打印信息、不启动服务）：

```bat
start.bat check
```

> **长期建议**：从 https://nodejs.org/ 安装一个 Node.js LTS。之后任何终端都能直接 `npm start`，也不再依赖 WorkBuddy 的目录（WorkBuddy 升级或卸载可能换掉便携版路径）。如果装到了别的位置，设一个用户环境变量 `WB_NODE_EXE` 指向 `node.exe` 即可。

### 4.2 方式 A：双击 `start.bat`（最简单）

双击后脚本会：定位 node → 检查 8787 端口是否已被占用 → 打印访问地址 → 自动打开浏览器 → 前台运行服务。

- **窗口保持打开 = 服务在运行**；关闭窗口或按 `Ctrl+C` 即停止。
- 若已在运行，会直接打开页面，不会重复启动第二个实例。
- 命令行里等价写法：`cd /d D:\lololololololololololololol\money` 然后 `start.bat`。

### 4.3 方式 B：后台无窗口运行 + 开机自启

| 文件 | 作用 |
|------|------|
| `run_hidden.vbs` | 双击后**无黑窗**后台启动，服务日志写入 `logs/server.log`（已被 `.gitignore` 忽略） |
| `status.bat` | 查看是否在运行、进程 PID，并请求 `/api/health` 做健康检查 |
| `stop.bat` | 停止占用 8787 端口的服务进程 |
| `setup_autostart.vbs` | 双击安装**当前用户登录时自动后台启动** |
| `remove_autostart.vbs` | 双击撤销开机自启 |

开机自启只是在当前用户的「启动」文件夹里放一个指向 `run_hidden.vbs` 的快捷方式，**不改注册表、不需要管理员权限**，以这种方式启动的进程独立于 WorkBuddy，关掉 WorkBuddy 也不会被带走。

### 4.4 方式 C：用 VSCode 或 IDEA 启动

有 VSCode / IDEA 完全够用，但要清楚：**它们是编辑器，不是 Node.js 运行时**，只是给你一个终端或一个「运行」按钮；真正执行 `server.js` 的还是 `node.exe`。因为便携版 Node 不在 PATH 里，直接用 IDE 的 Node 调试配置可能会报「找不到 Node」。

**VSCode（推荐）**：用 VSCode 打开 `money` 文件夹，然后二选一：

- 集成终端执行 `.\start.bat`；
- 按 `Ctrl+Shift+B` 或「终端 → 运行任务」，项目已配好 `.vscode/tasks.json`，内置 5 个任务：**启动（可见窗口）**、**后台启动（无窗口）**、**状态检查**、**停止服务**、**环境自检**。

**IntelliJ IDEA**：

- 最简单：打开 IDEA 内置终端，执行 `.\start.bat`；
- 或新建 **Shell Script** 运行配置，Script text 填 `.\start.bat`，Working directory 填项目目录；
- 若想用 Node.js 运行/调试配置，需在 `Settings → Languages & Frameworks → Node.js`（需 Node.js 插件）里把 Node interpreter 手动指向上面那个 `node.exe` 绝对路径。

### 4.5 其他实用场景

- **局域网/手机访问**：先 `set HOST=0.0.0.0` 再启动，用 `http://<本机局域网IP>:8787` 打开（需放行 Windows 防火墙）。
- **端口被占用**：先 `set PORT=9000` 再启动，`status.bat` / `stop.bat` 会跟着用同一个端口。
- **上游无网络**：页面显示空状态与错误提示，不会编造数据。
- **完全不想在本机跑**：可以把它发布成一个在线网址（云端托管），需要的话告诉我，我来部署。

## 七、后端接口

| 接口 | 说明 |
|------|------|
| `GET /api/health` | 服务状态、北京时间、A 股/港股交易状态、数据源列表 |
| `GET /api/indices` | 三大指数实时报价 + 当日分时点（价格、均价、分钟量、成交额）+ 数据时点 |
| `GET /api/sectors?type=industry\|concept\|region` | 全市场板块分页取数、去重、计算排序指标与资金汇总，返回完整排序列表（前端取前 10） |
| `GET /` | 静态页面（`public/` 下的资源） |

两个数据接口都支持 `force=1`（如 `/api/indices?force=1`）：跳过缓存强制回源，供手动「刷新数据」使用。缓存 TTL 随交易状态动态变化：盘中指数 0.9 秒 / 板块 4.5 秒，休市统一 60 秒，并分别使用 `live` / `closed` 缓存键。

数据源：东方财富公开行情接口 `push2.eastmoney.com`、`push2his.eastmoney.com`。接口字段在 `server.js` 中统一归一化，单位换算为「元 / 亿元」，所有时间统一标注为**北京时间**。

## 八、数据口径与已知限制

- **主力净额** = 超大单净额 + 大单净额，是按单笔成交规模分档的方向性差额**估算值**，非交易所官方数据，也不等于增量资金。
- **板块层级重叠**：东方财富行业板块包含一级/二级/三级分级行业，成分互相重叠；各行金额**不可相加**代表全市场总额。后端已对数值完全相同的重复口径条目去重（保留名称更短的一条），行业板块约 496 条原始记录去重后约 457 条。
- **非交易时段**展示最近交易日收盘数据，页面会明确标注数据时点。
- 上游接口为公开入口，可能限流或变更；失败时页面显示空状态与错误提示，**不会展示任何模拟数据**。
- 交易状态仅按北京时间时段与周末判断，法定节假日以交易所公告为准。
